# Cuckoo

Daily schedule alarm app. Sound + push notification per task.

## Setup
1. Create a new GitHub repo, push this project (root = repo root).
2. Go to Actions tab, run "Build Cuckoo APK" (or just push to `main`).
3. Check the "Releases" section of your repo — APK is attached there.
4. Download `app-debug.apk`, install on your phone (allow install from unknown sources).
5. On first launch: grant notification permission, grant "exact alarm" permission if prompted.

## Editing schedule
Tap an item to change its time. Tap the switch to enable/disable. Tap ✕ to delete.
Tap + (bottom right) to add a new task.

Default schedule is preloaded (Math, Chores, C++, Kotlin, Electronics, Electromagnetism, Review).
